# Stock Profit & Loss Calculator

A sleek, lightweight financial calculator built for traders to analyze stock returns instantly. It provides detailed metrics for both standard **Delivery (1x)** trades and leveraged **Intraday (Margin)** positions in real time.

## 🚀 Key Features

- **Real-Time Calculations:** Automatically computes trade metrics as you type without full page reloads.
- **Dual Trade Modes:**
  - **Delivery:** Standard 1x spot trade returns based on total capital.
  - **Intraday (Leverage):** Interactive margin multiplier options (2x, 3.3x, 5x, or custom) to calculate actual margin capital required and Return on Margin Capital (Margin ROI).
- **Comprehensive Outputs:**
  - Invested Amount (Total Buy Value)
  - Returns Amount (Total Sell Value)
  - Profit / Loss Amount
  - Profit / Loss Percentage (Standard ROI vs. Margin ROI)
- **Strict Input Validation:** Handles negative values, invalid characters, non-integer share counts, and division-by-zero gracefully.
- **Dynamic Visual Cues:** Modern dark-mode dashboard interface with real-time green (profit), red (loss), and neutral state badges.

## 🛠️ Built With

- **HTML5** – Semantic markup and structured accessibility.
- **CSS3** – Custom dark-mode styling, responsive grid layouts, and dynamic state styling.
- **JavaScript (Vanilla)** – Reactive state management and math logic without external framework dependencies.
